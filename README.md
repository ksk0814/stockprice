# 理論株価 算定Webアプリ

`StockPrice_ver2.py` をブラウザで使える Streamlit アプリにしたものです。計算ロジック（資産価値・事業価値・理論株価、上昇余地、PSR、時価総額/正味価値、投資判断）と Excel 出力（`StockPrice.xlsx` テンプレートへの書き込み）は元のスクリプトと同じです。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `app.py` | Web 画面（Streamlit） |
| `stockprice_core.py` | 読み込み・データ取得・計算・Excel 出力の処理 |
| `StockPrice.xlsx` | 出力用テンプレート（元のものと同じ） |
| `requirements.txt` | 必要なライブラリ |

## 起動手順（ローカル）

Python 3.9 以上が必要です。このフォルダで次を実行します。

```bash
pip install -r requirements.txt
streamlit run app.py
```

ブラウザが自動で開きます（開かない場合は http://localhost:8501 ）。終了はターミナルで `Ctrl + C` です。

## 使い方

1. **銘柄コードを入力**：4 桁のコード（例 `7203`、`130A`）を入れて「算定する」。IR BANK から `fy-balance-sheet.csv` / `fy-profit-and-loss.csv` を取得して計算します。IR BANK から取れない場合は Yahoo Finance の年次財務データ（総資産・自己資本・発行済株式数・EPS・純利益・売上高）から同じ指標を算出します。
2. **CSV ファイルをアップロード**：IR BANK からダウンロードした 2 つの CSV を選んで「算定する」。
3. 株価と流動資産は Yahoo Finance から自動取得します。取れなかったときは「入力データ」欄で手入力すると、その場で再計算されます。
4. 「Excel ファイルをダウンロード」で `StockPrice_<銘柄>.xlsx` を保存できます。C10 / C12 / C14 などの数式は Excel で開いたときに再計算されます。

## 元のスクリプトからの変更点

- 計算は同じですが、ターミナル出力の代わりに画面に指標・判定（OK/NG）・投資判断を表示します。
- CSV の列は見出し（総資産、BPS、自己資本比率、売上高、EPS、ROA など）で探し、見つからない場合は元のスクリプトと同じ列番号を使います。文字コードは UTF-8 / Shift_JIS のどちらでも読めます。
- PL の最終行が予想行で ROA が空欄のときは、1 つ前の実績行の ROA を使います（元のスクリプトでは止まっていました）。売上高は、予想行があればその 1 つ前、なければ最終行（最新の実績）を使います。
- 画面上の「時価総額/正味価値」は、正味価値（流動資産−負債）がマイナスのとき NG と表示します（Excel テンプレートの D14 はマイナスでも OK になります）。
