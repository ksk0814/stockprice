# 理論株価・IR レポート Webアプリ

`StockPrice_ver2.py`（理論株価）と `IR_report.ipynb`（業績推移・成長性レポート）を、ブラウザで使える 1 つの Streamlit アプリにまとめたものです。銘柄コードを入れると「総合判断／理論株価／業績・成長性（IR レポート）」の 3 タブで結果を表示します。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `app.py` | Web 画面（Streamlit） |
| `stockprice_core.py` | 理論株価（残余利益モデル）：読み込み・データ取得・計算・Excel 出力 |
| `ir_report_core.py` | IR レポート：業績推移・増収率/増益率・期末株価・PER・総合判断・Excel 出力 |
| `StockPrice.xlsx` | 旧方式のテンプレート（2026-10-28 の改修以降は使っていません。削除しても動きます） |
| `requirements.txt` | 必要なライブラリ |

## 起動手順（Mac）

ターミナルでこのフォルダに移動して、次の 2 行を実行します（`pip` / `streamlit` コマンドを直接使わず、`python3 -m` で呼び出します）。

```bash
python3 -m pip install --user -r requirements.txt
python3 -m streamlit run app.py
```

ブラウザが自動で開きます（開かない場合は http://localhost:8501 ）。終了はターミナルで `Ctrl + C` です。

Python 3.8（Mac 標準）とそれで入る Streamlit 1.40 でも動作します。新しい Streamlit でも同じコードで動きます。

## 使い方

1. **銘柄コードを入力**：4 桁のコード（例 `7203`、`130A`）を入れて「分析する」。IR BANK から `fy-balance-sheet.csv` / `fy-profit-and-loss.csv` を取得し、株価・期末株価・流動資産は Yahoo Finance から取得します。IR BANK から取れない場合は Yahoo Finance の年次財務データで代わりに計算します。
2. **CSV ファイルをアップロード**：IR BANK からダウンロードした CSV を選んで「分析する」。損益計算書だけでも IR レポートは作れます。
3. 画面上部の「現在の株価」は自動取得した値です。書き換えると（指値での試算など）全タブが再計算されます。
4. ダウンロード
   - 「総合判断」タブ：理論株価シート＋IR レポートシートをまとめた Excel
   - 「理論株価」タブ：計算式入りの Excel（前提条件のセルを書き換えると再計算され、誰でも検算できます）
   - 「業績・成長性」タブ：IR レポートだけの Excel（表・売上高/営業利益グラフ・EPS と株価の推移・EPS と株価の散布図）

## 理論株価の算定方法（残余利益モデル）

```
理論株価 = BPS + Σ(t=1..T) (ROE_t − r) × 期首BPS_t ÷ (1 + r)^t
```

- **BPS**：直近実績の 1 株当たり純資産
- **ROE（1年目）**：予想 EPS ÷ BPS（予想が無ければ直近 EPS）。画面で「過去3期平均 ROE」に切り替え可
- **r（株主資本コスト）**：既定 8%。伊藤レポート（経済産業省, 2014）が示した ROE の最低ライン
- **T（収れん年数）**：既定 10 年。ROE が T 年かけて r まで直線的に下がり、その後の超過利益は 0（保守的な前提）
- **配当性向**：IR BANK の配当 CSV（直近 3 期の中央値）。取れなければ 30% と仮定。BPS は「利益 − 配当」だけ増える（クリーンサープラス）

株価 ÷ 理論株価 − 1 が −30% 以下なら「割安圏」、+30% 以上なら「割高圏」、その間は「概ね理論株価の範囲内」です（Graham の安全余裕率の考え方）。
r ±1% の幅と、r（6〜10%）× T（5・10・15 年）の感応度表も表示します。前提は「理論株価」タブで変更できます。

### この手法を選んだ理由

旧方式（資産価値 = BPS × 割引評価率、事業価値 = EPS × ROA × 150 × 財務レバレッジ補正）は個人投資家向けに広まった経験式で、係数（150 倍、割引評価率の段階など）に理論的・実証的な裏付けがありません。
残余利益モデルは、純資産と利益だけで株主価値を表せる理論式で、B/S と P/L だけで計算でき、DCF・配当割引モデルより実際の株価をよく説明することが実証されています。日本公認会計士協会の企業価値評価ガイドラインにも掲載されている標準的な手法です。

- Ohlson, J. A. (1995) Earnings, Book Values, and Dividends in Equity Valuation. *Contemporary Accounting Research* 11(2).
- Frankel, R. & Lee, C. M. C. (1998) Accounting Valuation, Market Expectation, and Cross-sectional Stock Returns. *Journal of Accounting and Economics* 25(3).
- Lee, C. M. C., Myers, J. & Swaminathan, B. (1999) What is the Intrinsic Value of the Dow? *Journal of Finance* 54(5).
- Francis, J., Olsson, P. & Oswald, D. (2000) Comparing the Accuracy and Explainability of Dividend, Free Cash Flow, and Abnormal Earnings Equity Value Estimates. *Journal of Accounting Research* 38(1).
- 日本公認会計士協会『企業価値評価ガイドライン』（経営研究調査会研究報告第32号, 2013年改正）
- 経済産業省『持続的成長への競争力とインセンティブ』（伊藤レポート, 2014年）

### 限界

- 金融業（銀行・保険）は資本規制のため ROE の意味が異なり、参考程度にしてください。
- 債務超過（BPS がマイナス）の企業は計算できません。大きな赤字の企業は理論株価がマイナスになり「評価不能」となります。
- 一時的な特別損益で EPS がぶれる場合は「過去3期平均 ROE」を選んでください。

## 総合判断の考え方

次の 3 つをそれぞれ +1／0／−1 で点数化し、合計で「割安」「やや割安」「中立」「やや割高」「割高」の 5 段階に分けます（売買の推奨はしません）。

- 理論株価との乖離：株価が理論株価を 30% 以上下回れば +1、30% 以上上回れば −1
- 成長性（直近 3 期平均の 増収率＋増益率）：20% 以上かつ両方プラスで「高成長」+1、合計マイナスで「業績悪化」−1
- 過去 PER との比較：過去の期末 PER 中央値 × 直近 EPS（予想があれば予想）を目安株価とし、現在値より 10% 以上高ければ +1、10% 以上低ければ −1

EPS と株価の相関が弱い（0.3 未満）銘柄には、PER による目安は参考程度にするよう注意書きを出します。

## IR_report.ipynb からの変更点

- Google ドライブのマウントや CSV の事前ダウンロードは不要です。
- `-` や空欄の値は欠損として扱い、その年度の率だけ空欄にします（元のノートブックで出ていた ValueError は起きません）。
- 期末株価は `Close.xlsx` を使わず、Yahoo Finance の月足から各決算月の月末終値を取得します。
- 増収率・増益率（営業利益）は前期比の伸び率（例 5.0%）で表示します（元は倍率 105% の形）。元の F 列の数式（`D6+E5`）は 1 行ずれていたため、成長性は同じ年度の「増収率＋増益率」で計算しています。
- 追加した指標：直近 3 期平均、EPS 年平均成長率（最大 10 年）、EPS と株価の相関係数、期末 PER の推移と中央値、PER から見た目安株価。

## StockPrice_ver2.py からの変更点

- 2026-10-28：理論株価の算定式を残余利益モデルに置き換えました（上記）。以下は置き換え前の変更点です。
- ターミナル出力の代わりに画面に指標・判定（OK/NG）・投資判断を表示します。
- CSV の列は見出し（総資産、BPS、自己資本比率、売上高、EPS、ROA など）で探し、見つからない場合は元のスクリプトと同じ列番号を使います。文字コードは UTF-8 / Shift_JIS のどちらでも読めます。
- PL の最終行が予想行で ROA が空欄のときは、1 つ前の実績行の ROA を使います。売上高は、予想行があればその 1 つ前、なければ最終行（最新の実績）を使います。
- 画面上の「時価総額/正味価値」は、正味価値（流動資産−負債）がマイナスのとき NG と表示します（Excel テンプレートの D14 はマイナスでも OK になります）。
